Access keys help you if you have difficulty using a pointing device, such as a mouse. These keyboard shortcuts give you a different way to navigate this service.

Press the 'alt' key and another key at the same time to perform a certain function. For example, 'alt' and 'I' will submit whatever you've entered or selected on a page.

The access keys you can use appear in brackets throughout the system.
